# Simple Calculator

## Usage

The Simple Calculator is a web-based application that allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division. The calculator provides a user-friendly interface with a display box and a set of buttons for the various operations.

##
To use the calculator, follow these steps:

1. Open the `index.html` file in a web browser.
2. The calculator interface will be displayed on the screen.
3. Click on the buttons to enter the numbers and operators you want to use.
4. The result of the calculation will be displayed in the display box.
5. To clear the display, click the "C" button.
6. To perform a new calculation, simply enter the new numbers and operators.

##
The calculator also supports decimal numbers and negative numbers. Simply click the "." button to enter a decimal point, and the "-" button to enter a negative number.
##
The calculator is built using HTML, CSS, and JavaScript. The `index.html` file contains the structure of the calculator interface, the `style.css` file contains the styling, and the `script.js` file contains the JavaScript code that handles the calculator's functionality.
